# README demo (English)

The demo video shown in the repo README, made with voiceover-studio itself. Screenshots come from
`examples/make_readme_demo_shots.py`; build it with the commands in `examples/README.md`.

### Scene 1: Title card
**On screen:** title card.
**Narration:**
This video was made with voiceover-studio. It turns a script and a few screenshots into a narrated demo, in a cloned voice, entirely on your own computer.

### Scene 2: Write the script
**On screen:** pitch.md in an editor; highlight the narration lines.
**Narration:**
First, write the script. Each scene is one screen, and only the narration paragraph is spoken, sentence by sentence.

### Scene 3: Mark the highlights
**On screen:** cues.json; highlight the two cue lines.
**Narration:**
Next, mark what to highlight. Each highlight is tied to a word in the narration, so it lights up exactly when that word is spoken.

### Scene 4: Run three commands
**On screen:** terminal; highlight the commands, then their output.
**Narration:**
Then run three commands. The voice is generated phrase by phrase, and the captions and highlights are timed to it automatically.

### Scene 5: Closing
**On screen:** closing card.
**Narration:**
It works in Bangla and English. It is free, and it is open source. Thank you for watching.
