# README demo (Bangla)

The demo video shown in the repo README, made with voiceover-studio itself. Screenshots come from
`examples/make_readme_demo_shots.py`; build it with the commands in `examples/README.md`.

### Scene 1: Title card
**On screen:** title card.
**Narration:**
এই ভিডিওটি তৈরি হয়েছে ভয়েসওভার স্টুডিও দিয়ে। এটি একটি স্ক্রিপ্ট আর কয়েকটি স্ক্রিনশট থেকে ক্লোন করা কণ্ঠে পুরো একটি ডেমো ভিডিও বানায়, সম্পূর্ণ আপনার নিজের কম্পিউটারে।

### Scene 2: Write the script
**On screen:** pitch.md in an editor; highlight the narration lines.
**Narration:**
প্রথমে স্ক্রিপ্ট লিখুন। প্রতিটি দৃশ্য একটি স্ক্রিন, আর শুধু ন্যারেশন অংশটুকুই বাক্য ধরে ধরে পড়া হয়।

### Scene 3: Mark the highlights
**On screen:** cues.json; highlight the two cue lines.
**Narration:**
এরপর ঠিক করুন কোথায় হাইলাইট হবে। প্রতিটি হাইলাইট ন্যারেশনের একটি শব্দের সাথে যুক্ত, তাই ঠিক সেই শব্দ বলার মুহূর্তেই এটি জ্বলে ওঠে।

### Scene 4: Run three commands
**On screen:** terminal; highlight the commands, then their output.
**Narration:**
তারপর তিনটি কমান্ড চালান। কণ্ঠ তৈরি হয় বাক্য ধরে ধরে, আর ক্যাপশন ও হাইলাইট নিজে থেকেই তার সাথে মিলে যায়।

### Scene 5: Closing
**On screen:** closing card.
**Narration:**
এটি বাংলা ও ইংরেজি দুই ভাষাতেই কাজ করে। এটি বিনামূল্যে, এবং ওপেন সোর্স। দেখার জন্য ধন্যবাদ।
